# 第 19 章：按需加载 Skills

知道“单元测试命令是 `npm run test:unit`”，还不足以完成一次可靠的代码审查。Agent 还需要一种方法：先看改动范围，再检查行为与测试，最后给出能定位到文件的发现。把所有任务的方法都放进常驻提示，会让每次简单提问也携带大量无关内容。

Skill 把某类任务的做法放在一个目录中：名称和简介说明什么时候用，`SKILL.md` 正文说明怎么做，参考文件补充细节。本章让程序先发现简介，再只加载当前需要的正文和资源。它给模型工作方法，真正的查文件、改文件、运行命令仍由原来的工具完成。

## 一次 review 怎样取得所需方法

我们准备一个 `review` 技能，要求核对实现、测试与实际结果。开始时模型只知道它适合代码审查；用户手动加载或模型请求加载后，下一次请求才携带完整步骤。若正文还引用 `references/checklist.md`，模型再读取那份清单，让实际内容回到后续判断。

这条路径把“发现技能”“取得方法”“执行任务”分开观察。目录中存在一个名字，不表示正文已经进入请求；读取一份脚本，也不表示运行过它。
