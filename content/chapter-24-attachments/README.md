# 第 24 章：让附件以可核对的身份进入上下文

用户写“请看 `screens/error.png`”，远端模型只会收到一个路径字符串。本章让用户显式选择本地文件，使经过检查的文本或图片真正进入模型请求；同时记录它属于哪条消息、内容有没有变化，以及恢复会话后还能不能使用。

我们先把一份需求文本附到问题，再把同样机制扩展到截图。两者共用附件引用，真正内容在发请求前重新读取和校验，最后由各协议适配器转换成请求内容。

## 一份附件怎样从磁盘走到模型

`/attach` 登记待发送引用；提交问题时，引用关联到 user 消息；发请求前，程序核对路径、类型、大小与摘要，再把文本或图片装入请求。模型根据收到的材料作出判断，缺少证据时仍应继续读取或说明不足。

会话只保存引用，不保存原始文件字节。恢复记录后，我们能知道曾经附过什么，却不能从一个路径或摘要还原旧内容。因此旧附件需要显式重新附加，磁盘当前文件才会再次参与请求。
