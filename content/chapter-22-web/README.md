# 第 22 章：取得外部资料，再依据来源完成任务

用户给出一个文档链接，请 Agent 按当前 API 修改代码。模型记得参数名，不代表它读过这个页面；搜索命中一条链接，也不代表回答中的具体主张得到支持。本章把外部资料查询分成三个能分别检查的步骤：读取已知页面、发现候选来源、让回答对应实际取得的资料。

程序负责真正发出网络请求，限制时间和读取规模，并保存 URL 与正文。模型根据这些工具结果判断资料是否相关，决定是否继续查询、怎样修改代码、在回答中引用什么。本地权限规则继续由程序执行，网页文字不能直接授予操作权限。

## 一条资料请求怎样走到代码修改

已知地址时，`web_fetch` 取得页面正文；没有地址时，`web_search` 先取得标题、URL 与摘要，再选择需要展开的页面。模型随后结合本地代码作出修改，并在说明参数规则时引用实际读到的来源。

这条路线区分“取到了什么”和“据此能说什么”。工具返回资料是必要的一步，来源是否支持结论还需要判断；一个链接形状不能代替核对正文，一份文档也不能代替本地编译与测试。
