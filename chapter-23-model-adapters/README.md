# 第 23 章：让模型切换遵守同一套执行规则

第 2 章已经接通 OpenAI 兼容协议与 Anthropic Messages。本章回到这个出口，检查后面增加的工具、预算和任务控制是否始终遵守相同规则：完整工具调用才执行，结果按调用编号回送，任务中途不悄悄换连接，服务没报告的用量保持未知。

我们用同一个任务贯穿本章：“读取 `package.json`，说明启动命令。”两种协议应该都能让模型提出读取、接收结果、再给出答案。实现形式可以不同，动作与结果的因果关系必须保留。

## 从内部消息到下一次模型决策

主循环保存用户消息、模型工具请求及工具结果；协议适配器把它们转换成当前服务接受的 JSON，并把响应整理成内部结果。模型配置决定这次请求发往哪里、使用哪个模型及本地声明的能力。错误和用量则帮助我们解释这次请求实际取得了什么。

这三层各有可检查的结果。适配成功不证明远端支持所有特性；切换命令成功不证明远端模型 ID 可用；流里显示过字符，也不证明最终响应用量已经收到。
