OpenAI 与 Anthropic 两个实际 SDK 分别连接本地可控 HTTP 服务，模拟 429 后成功并断言恰好两次请求。检查区分输出文字前的连接失败和已经显示文字后的断线：前者满足条件时可有限重试，后者明确失败。已有 `write_file` 调用实际只执行一次；重试针对随后的单次模型请求，不重放整个 Agent Loop 或工具。退避可被取消，所有尝试共用原来的请求期限。

无进展检查覆盖取消信号发出后继续等待原任务和真实资源清理，以及人工审批和问答期间暂停计时。额外审查发现子任务审批没有暂停父计时，已改在实际处理审批 Promise 的边界计数；父任务 40ms 上限、每次人工审批 120ms 时，delegate 和两次串行审批的共享 worker 均能完成，避免靠父层事件显示猜测用户是否仍在等待。

`--doctor` 用无凭据的本地配置分支检查，`--quiet` 保留必要交互、结果与错误。新增超时默认值曾干扰上一章管理命令的独占参数校验，已修正并复核：单独 `--sandbox-info` 返回 0，显式混用 `--idle-timeout` 仍拒绝。
