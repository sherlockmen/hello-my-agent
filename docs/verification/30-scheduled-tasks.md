## 实现与边界

创建只保存规则，不启动模型。唯一写入者持有整个服务生命周期的文件锁；状态按有界白名单校验，写临时文件、同步后再 rename。密钥与完整模型配置不写入调度状态。

每次运行先持久保存次数和 token 预留，再启动独立只读子会话。预留是保守的本地上限，不是费用账单；失败与恢复都不退还。实际 runner 结束且终态保存成功前，任务一直占有运行位置。错过多个触发点只合并成一次，不追补积压。

暂停只挡后续触发；停止先保存规则，再请求取消并等待当前运行与结果保存。正常退出等待所有活跃任务；强制结束后必须明确恢复，把遗留 running 标为 interrupted，暂停规则、保留预算，不能推断远端状态，也不自动重跑。写入失败会封住后续写操作并退出服务，等待已有资源收尾后释放锁；普通输入错误继续接受控制命令。
