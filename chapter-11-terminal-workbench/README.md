# 第 11 章：把终端变成可以编辑和浏览的工作区

[11.1 让多行输入成为可编辑的草稿](01-editable-draft/README.md) · [11.2 取回旧问题，补全当前文字](02-recall-and-complete/README.md) · [11.3 在输出继续时，停下来浏览结果](03-browse-results/README.md) · [11.4 把长草稿交给外部编辑器](04-external-editor/README.md) · [11.5 按终端列宽排版，保留阅读位置](05-terminal-layout/README.md) · [练习与答案](EXERCISES.md)

第十章已经能输入问题、查看进展、审批工具和取消任务。本章把这些操作接成一个日常工作过程：先整理请求，发送后回看结果，再准备下一份。

界面要记住尚未发送的文字，也要记住正在读哪里。模型与工具沿用已有执行核心，本章逐步补上这些人的操作。

## 从同一份读取请求开始

```text
请读取 README.md
说明启动和检查方法
```

先在文件名前插入“项目中的 ”，再撤销，检查好以后发送。读完回答，要看 `package.json`，就取回原问题、补全文件名；输出还在继续时，向上停下来核对；要求变长了，用外部编辑器整理；窗口变窄了，重新换行后仍找到刚才的文字。

每节的动画沿用 A3 操作特写：下方的大按键下压变色，或事件卡先说明收到什么，再展示程序怎样改数据、显示结果。“问题”动画演示本节想完成的操作，“工作原理”动画解释对应的方法。蓝色表示位置或选取范围，橙色突出本次操作和变化，灰色保留旧内容；手绘 TUI 是教学示意，配有同步的静态图。

| 小节 | 新增功能 | 主要办法 |
| --- | --- | --- |
| [11.1 多行草稿](01-editable-draft/README.md) | 多行编辑、多行粘贴、撤销与重做 | 正文与光标一起保存在内存中，整段粘贴一次插入，改字前留下旧版本 |
| [11.2 取回与补全](02-recall-and-complete/README.md) | 输入历史、历史搜索、文件与命令补全 | 保存已提交的普通问题；按关键词取回，按实际名称匹配，多个匹配只补共同前缀 |
| [11.3 浏览结果](03-browse-results/README.md) | 焦点、滚动、折叠、复制 | 切换焦点；保存消息、排成显示行、按阅读位置取一屏，End 恢复跟随；保留完整正文供复制 |
| [11.4 外部编辑](04-external-editor/README.md) | 外部编辑器 | 暂停 TUI，用临时文件交换草稿，等编辑器退出后读回 |
| [11.5 终端排版](05-terminal-layout/README.md) | 中文宽度、resize、无颜色显示 | 按完整字符占用的列宽换行，按消息中的文字位置找回；用文字保留角色、状态与焦点提示 |

取回、补全和编辑都先改变草稿，向上翻只改变阅读位置；明确发送以后，正文才交给已有 Agent Loop。11.3 开始可以在任务运行中编辑下一份草稿，执行仍一次一轮。第十二章再处理运行中干预和排队，第十三章再保存会话；本章输入记录只留在当前进程。

## 从哪里继续，怎样跟写

起点是 [10.4](../chapter-10-terminal-ui/04-cancel-and-restore/README.md) 与[第十章练习](../chapter-10-terminal-ui/EXERCISES.md)。练习新增独立实验，没有改变正式实现，11.1 直接从 10.4 的完整 `src/` 继续。

五节各有独立 `README.md + src/`，依次沿用上一节。“动手构建”给出本节改动文件与精确替换范围，完整代码可展开跟写；没有列出的实现继续沿用。教学示意帮助理解方法，不代替配套源码。

完成 11.5 后做[章末练习](EXERCISES.md)，把连续操作写成可以重复运行的检查。使用完整配套仓库时，在仓库根目录运行：

```bash
npm run check:11
```

固定输入与伪终端检查覆盖编辑、粘贴、浏览和尺寸变化。模型、剪贴板、编辑器使用本地替身，不调用真实模型，也不改系统剪贴板；终端检查需要 macOS、Linux 或 WSL 中的 `python3`，只用标准库。各节的手动验证用来观察本机终端、字体、输入法与编辑器的实际表现。
